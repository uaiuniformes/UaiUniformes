# **App Name**: Lacort ProdTrack

## Core Features:

- Login: User authentication using email and password, including password recovery and real-time validation.
- Production Dashboard: Dashboard displaying real-time production status, including active orders, production stages (Cutting, Printing, Sewing, Finishing), and completed/delivered orders.
- Customer Module: Customer data storage and management, with fields for company name, contact person, position, email, phone, address, and CNPJ (Brazilian business ID).
- Quotation Module: Quotation creation and management per customer, including data fields for creation date, expiration date, product type, color, and print type.
- Order Module: Order registration and tracking from start to finish, including fields for customer, model, color, type (Silk, Sublimation, Embroidery, etc.), order and delivery dates, value, current stage, responsible person, notes, and artwork status.
- Production Menu: Production menu for each sector (Cutting, Silk, Embroidery, Sublimation, Sewing, Finishing), providing filtered views of orders.
- Automated WhatsApp Notifications: Tool which allows automatic notifications via WhatsApp to keep customers informed about their order status (received, in cutting, in print, in sewing, finished, delivered). The tool decides what (if any) notifications make sense.

## Style Guidelines:

- Primary color: Dark blue (#4A6484), based on the Lacort logo, for a professional and reliable feel.
- Background color: Light gray (#F0F0F0), a desaturated tint of the primary color, to provide a clean and neutral backdrop.
- Accent color: Green (#4CAF50), analogous to blue on the color wheel but with higher brightness and saturation, used for highlighting active steps/statuses, calls to action and interactive elements.
- Body and headline font: 'Inter' sans-serif for a modern, machined, objective, neutral look; it works well for both headlines and body text.
- Simple, clean icons to represent different production stages and modules.
- Clean and intuitive layout with cards for displaying production stages and orders.
- Subtle animations for transitions and status updates.
